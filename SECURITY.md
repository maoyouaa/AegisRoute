# Security policy

## Supported versions

Until v0.1.0 is released, the project is an implementation-in-progress portfolio system and has no production-supported version.

## Reporting a vulnerability

Do not open a public Issue for a suspected vulnerability that exposes credentials, personal data, or an actionable exploit. Contact the repository owner through the private vulnerability-reporting feature on GitHub once enabled.

Include the affected commit, reproduction conditions, impact, and any suggested mitigation. Do not include real user data or live credentials.

## Security boundary

v0.1 uses synthetic data and an internal-only Control Plane. It does not claim production IAM, GDPR compliance, SOC 2, ISO 27001, or fitness for sensitive data. See the threat model for current trust boundaries and known gaps.
